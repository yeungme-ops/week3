# AISCI210-Unit1-ML

Materials for the machine learning unit of UC Irvine AI SCI 210, beginning Thursday of Week 3 (October 15, 2026).

1. Click **Use this template** to create your own private repository.
2. In your repository, choose **Code → Codespaces → Create codespace on main**.
3. Wait for setup to finish. When opening a notebook, select **.venv** as its Python kernel.

The Python 3.12 environment includes scikit-learn, NumPy, pandas, Matplotlib, Seaborn, Vega-Altair, and Plotly Express. Package versions are pinned in `requirements.txt`.

The environment is checked each time the Codespace starts. Packages are installed on the first start and when requirements change; ordinary restarts reuse the existing environment.
